    How the ranking works

    A drug reaches a disease through a two-step path. It targets a gene, and that gene connects to the disease. We add up every path a drug has into a disease and rank drugs by the total.

    Not every path counts the same. A gene that hundreds of drugs hit tells you almost nothing, because everything runs through it. We divide each path by how connected its gene and drug are, using the damping exponent w = 0.4 from Project Rephetio. A path through a rare, specific gene counts for far more than one through a hub.

    Open Targets scores some gene-disease links using evidence pulled from known drugs. That would let us read the answer off the back of the book, so we cut it. Every number on this page comes from genetics, animal models, gene expression, and scientific literature. Nothing drug-derived.

    Method from Himmelstein et al., Project Rephetio, eLife 2017. Data from the Open Targets Platform. Related work: TxGNN, Nature Medicine 2024.
