# Pipeline

Run these in order. Each step reads what the last one wrote.

```
1. select_diseases.py    screens the full ontology, writes generated_diseases.py
2. fetch.py               pulls genes, interactions, and drugs from Open Targets
3. score.py                ranks candidates, writes web/data/results/
4. validate.py             measures ranking quality against known treatments
5. analysis.py              sensitivity, bootstrap, ablation, negative control
6. mechanism_direction.py   genetic-concordance check, independent of the score
7. trial_check.py           cross-checks top candidates against ClinicalTrials.gov
8. audit_novelty.py         flags candidates that may already be approved
```

`diseases.py` holds the curated 100 diseases and is not run directly; every other
script imports it. `generated_diseases.py` is not hand-written either. It is
regenerated by `select_diseases.py` and gets overwritten each time that runs.

A cold run of `fetch.py` takes about ten minutes and caches everything to
`data/raw/`. Every script after it runs in seconds, since they all read from
that cache. Re-running `fetch.py` is safe and fast: it skips anything already
cached, so a failed or interrupted run just picks back up.

See the root [README](../README.md) for what each script actually measures and why.
